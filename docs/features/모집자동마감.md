# 모집 자동 마감 기능명세서

> GitHub Issue: #20

## 1. 개요

경기 날짜와 시간이 지난 모집글을 자동으로 마감(closed) 처리하는 기능.
현재는 작성자가 수동으로 마감하거나, 정원이 찬 경우에만 자동 마감됨.

## 2. 만료 판별 기준

- `RecruitPost.date` (예: "2026-09-22") + `RecruitPost.time` (예: "18:00")을 조합하여 경기 시작 시각 생성
- 현재 시각 >= 경기 시작 시각이면 **만료**로 판별

## 3. 자동 마감 처리 흐름

### 3-1. 클라이언트 사이드 (실시간 처리)

```
useRecruitPosts 훅
  → onSnapshot으로 open 게시글 수신
  → 각 게시글의 date+time을 현재 시각과 비교
  → 만료된 게시글 발견 시:
    1. Firestore에 status: "closed" 업데이트 (closeRecruitPost 호출)
    2. 로컬 상태에서도 즉시 필터링
```

### 3-2. 모집글 상세 페이지

```
recruit/[postId]/page.tsx
  → 페이지 로드 시 만료 여부 체크
  → 만료된 글이면 자동 마감 처리 + "마감된 모집입니다" 표시
  → 참가 신청 버튼 비활성화
```

## 4. 과거 날짜 선택 방지

- 글 작성(/create) 페이지의 날짜 입력 필드에 `min` 속성 추가
- 오늘 이전 날짜는 선택 불가
- 수정 페이지에서도 동일 적용

## 6. 영향 범위

| 파일 | 변경 내용 |
|------|-----------|
| `src/lib/utils/dateUtils.ts` | 만료 판별 유틸 함수 (신규) |
| `src/hooks/useRecruitPosts.ts` | 만료 글 자동 마감 로직 추가 |
| `src/app/recruit/[postId]/page.tsx` | 상세 페이지 만료 체크 |
| `src/app/create/page.tsx` | 과거 날짜 선택 방지 |
| `src/app/recruit/[postId]/edit/page.tsx` | 수정 시 과거 날짜 방지 |

## 7. 예외 처리

- time 값이 없는 경우 해당 날짜 23:59으로 간주
