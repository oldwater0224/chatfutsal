# 참가 신청/수락 시스템 기능명세서

## 1. 개요

모집글 작성자와 참가 희망자 간의 참가 신청 → 수락/거절 플로우를 구현한다.
현재는 채팅으로만 의사소통이 가능하지만, 이 시스템을 통해 모집 현황을 정량적으로 관리할 수 있게 된다.

## 2. 용어 정의

| 용어 | 설명 |
|------|------|
| 작성자(Author) | 모집글을 작성한 사용자 |
| 신청자(Applicant) | 참가를 신청한 사용자 |
| 신청(Application) | 신청자가 모집글에 참가 의사를 표시하는 행위 |

## 3. Firestore 데이터 모델

### 3-1. applications 컬렉션 (신규)

```
/applications/{applicationId}
{
  postId: string           // 모집글 ID
  postTitle: string        // 모집글 제목 (알림/목록 표시용)
  applicantId: string      // 신청자 UID
  applicantName: string    // 신청자 닉네임
  authorId: string         // 작성자 UID
  message: string          // 신청 메시지 (선택)
  status: "pending" | "accepted" | "rejected"
  createdAt: Timestamp
  updatedAt: Timestamp
}
```

### 3-2. recruitPosts 컬렉션 (필드 추가)

```
기존 필드 유지 +
{
  acceptedCount: number    // 수락된 인원 수 (기본값: 0)
  applicantIds: string[]   // 신청한 유저 ID 목록 (중복 신청 방지용)
}
```

## 4. 기능 상세

### 4-1. 참가 신청

- **위치**: 모집글 상세 페이지 하단 CTA 버튼
- **조건**:
  - 로그인 상태
  - 본인 글이 아닐 것
  - 모집 상태가 open일 것
  - 이미 신청하지 않았을 것
- **플로우**:
  1. "참가 신청" 버튼 클릭
  2. 신청 메시지 입력 모달 표시 (선택사항)
  3. 확인 클릭 시 applications 문서 생성
  4. recruitPosts.applicantIds에 신청자 ID 추가
  5. 버튼이 "신청완료" 상태로 변경 (비활성)
- **신청 취소**:
  - pending 상태일 때만 가능
  - application 문서 삭제, applicantIds에서 제거

### 4-2. 신청 목록 조회 (작성자)

- **위치**: 모집글 상세 페이지 내 "신청 현황" 섹션
- **표시 정보**:
  - 신청자 닉네임, 신청 메시지, 신청 시간
  - 상태별 표시: 대기중(노란색), 수락(초록색), 거절(빨간색)
- **정렬**: 최신 신청 순

### 4-3. 수락/거절

- **위치**: 신청 목록의 각 항목에 수락/거절 버튼
- **수락 플로우**:
  1. 수락 버튼 클릭
  2. application.status → "accepted"
  3. recruitPosts.acceptedCount += 1
  4. acceptedCount >= needCount이면 자동으로 모집 마감 (status → "closed")
- **거절 플로우**:
  1. 거절 버튼 클릭
  2. application.status → "rejected"
  3. recruitPosts.applicantIds에서 제거 (재신청 가능하도록)

### 4-4. 모집 현황 표시

- **위치**: 모집글 카드, 모집글 상세 페이지
- **표시**: `현재인원/모집인원` (예: 2/5명)
- **프로그레스 바**: 시각적으로 모집 진행률 표시

### 4-5. 내 신청 내역 (마이페이지)

- **위치**: 마이페이지에 "내 신청 내역" 메뉴 추가
- **표시**: 신청한 모집글 목록 + 각 신청 상태

## 6. 제약사항

- Firestore 보안 규칙은 이 명세서 범위에서 제외 (별도 작업)
- 푸시 알림은 이 명세서 범위에서 제외 (별도 기능)
- 신청 메시지는 최대 100자로 제한
