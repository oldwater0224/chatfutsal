# 카카오 간편로그인 기능명세서

> GitHub Issue: #21

## 1. 개요

현재 이메일/비밀번호 방식만 지원하는 인증에 카카오 간편로그인을 추가.
Firebase Authentication과 카카오 OAuth를 연동하여 기존 유저 시스템과 통합.

## 2. 인증 흐름

```
사용자 → 카카오 로그인 버튼 클릭
  → 카카오 SDK 인증 (인가 코드 발급)
  → Next.js API Route로 인가 코드 전송
  → API Route에서:
    1. 카카오 서버에 액세스 토큰 요청
    2. 액세스 토큰으로 카카오 사용자 정보 조회
    3. Firebase Admin SDK로 Custom Token 생성
    4. Custom Token을 클라이언트에 반환
  → 클라이언트에서 signInWithCustomToken으로 Firebase 인증 완료
  → Firestore users 컬렉션에 프로필 저장/업데이트
  → 홈으로 이동
```

## 3. 카카오 개발자 설정 (사전 작업)

- Kakao Developers(https://developers.kakao.com) 앱 생성
- 플랫폼 > Web > 사이트 도메인 등록 (localhost:3000 + 배포 도메인)
- 카카오 로그인 활성화
- Redirect URI 등록: `{도메인}/api/auth/kakao/callback`
- 동의 항목: 닉네임 (필수), 프로필 이미지 (선택)

## 4. 환경 변수

```env
NEXT_PUBLIC_KAKAO_JS_KEY=       # 카카오 JavaScript 키
KAKAO_REST_API_KEY=             # 카카오 REST API 키
NEXT_PUBLIC_KAKAO_REDIRECT_URI= # 리다이렉트 URI

# Firebase Admin (서버 사이드 Custom Token 생성용)
FIREBASE_ADMIN_PROJECT_ID=
FIREBASE_ADMIN_CLIENT_EMAIL=
FIREBASE_ADMIN_PRIVATE_KEY=
```

## 5. 구현 상세

### 5-1. 카카오 SDK 초기화

```typescript
// src/lib/kakao/kakaoAuth.ts

- Kakao.init(JS_KEY) — 앱 초기화
- Kakao.Auth.authorize({ redirectUri }) — 로그인 요청
```

### 5-2. API Route (서버 사이드)

```
POST /api/auth/kakao
  Request: { code: string }  (인가 코드)
  Response: { token: string } (Firebase Custom Token)

처리 순서:
  1. 인가 코드 → 카카오 토큰 발급 (POST https://kauth.kakao.com/oauth/token)
  2. 액세스 토큰 → 사용자 정보 조회 (GET https://kapi.kakao.com/v2/user/me)
  3. Firebase Admin으로 Custom Token 생성 (uid: "kakao_{카카오ID}")
  4. Firestore users 컬렉션에 사용자 정보 upsert
```

### 5-3. 클라이언트 로그인 처리

```typescript
// src/lib/kakao/kakaoLogin.ts

async function loginWithKakao():
  1. 카카오 인가 코드 획득 (리다이렉트 방식)
  2. 콜백 페이지에서 code 파라미터 추출
  3. /api/auth/kakao에 code 전송
  4. 받은 Custom Token으로 signInWithCustomToken(auth, token)
  5. 홈으로 리다이렉트
```

### 5-4. 콜백 페이지

```
/api/auth/kakao/callback (또는 /auth/kakao/callback 페이지)
  → URL에서 code 파라미터 추출
  → API Route 호출 → Custom Token 수신
  → Firebase 인증 완료 → 홈으로 이동
```

### 5-5. Firestore 유저 데이터

```typescript
// 카카오 로그인 시 저장할 유저 데이터
{
  uid: "kakao_123456789",
  email: null,                    // 카카오에서 이메일 미제공 시
  displayName: "카카오닉네임",
  provider: "kakao",              // 로그인 제공자 구분용 (신규 필드)
  profileImage: "https://...",    // 카카오 프로필 이미지 (선택)
  createdAt: Date,
}
```

## 7. User 타입 변경

```typescript
export interface User {
  uid: string;
  email: string | null;       // 카카오 유저는 null 가능
  displayName: string;
  provider?: "email" | "kakao"; // 신규 필드
  profileImage?: string;        // 신규 필드
  createdAt: Date;
}
```

## 10. 주의 사항

- 카카오 CI/BI 가이드 준수 (버튼 색상 #FEE500, 로고 사용 규정)
- 카카오 계정과 기존 이메일 계정은 별도 계정으로 관리 (추후 연동 기능은 별도 이슈)
- Firebase Admin Private Key는 환경 변수로만 관리, 절대 코드에 포함 금지
